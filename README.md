# Vyomesh Kumar portfolio — GitHub Pages export

This archive contains only the finalized published website. HTML, CSS, JavaScript, images, favicon, and resume are unchanged from the latest deployed artifact. No build step, package installation, framework, backend, or API keys are needed.

## Publish

1. Create or open the GitHub repository `vyomeshk2006-code.github.io` under `vyomeshk2006-code`.
2. Extract this ZIP and upload its contents to the repository root. `index.html` must be at the root, not inside an extra folder. Include `.nojekyll`.
3. In repository Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. After GitHub completes deployment, visit https://vyomeshk2006-code.github.io/.

The empty `.nojekyll` file tells GitHub Pages to serve the static files without Jekyll processing. No CNAME is needed for this GitHub-provided address.

All section links, project links, email links, resume download, mobile navigation, progressive reveals, blue border glow, and reduced-motion support remain in the original source.
